Tentang Backup & Restore

Panduan penting terkait format data, rutinitas pencadangan, dan keamanan pemulihan database.

  • File backup berformat .sql salinan lengkap seluruh tabel dan data notulen Anda.
  • Simpan file backup di tempat yang aman, seperti Google Drive, USB, atau server cadangan.
  • Disarankan membuat backup secara rutin minimal seminggu sekali, terutama setelah input data baru.
  • Riwayat backup hanya tersimpan di browser ini (localStorage). Bersihkan cache akan menghapus log riwayat.
  • Restore: Klik tombol Pulihkan (.sql) dan pilih file backup untuk mengembalikan seluruh data notulen. Perhatian: data yang ada akan digantikan oleh data dari file backup!
